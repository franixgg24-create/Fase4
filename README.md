Software FJ
De qué trata este proyecto?
Software FJ es un programa desarrollado en Python que permite gestionar clientes, servicios y reservas de una manera sencilla y organizada.
Este proyecto se realizó como parte de una actividad académica, con el propósito de poner en práctica los conocimientos adquiridos sobre programación orientada a objetos y desarrollar un sistema que permita realizar diferentes operaciones desde un menú principal.

¿Qué permite hacer?
El programa cuenta con las siguientes opciones:
Registrar nuevos clientes.
Registrar los servicios disponibles.
Crear reservas asociadas a un cliente y un servicio.
Consultar los clientes registrados.
Consultar los servicios disponibles.
Consultar las reservas realizadas.

¿Cómo está organizado?
El proyecto está dividido en diferentes archivos para mantener el código organizado y facilitar su comprensión.
También cuenta con carpetas para almacenar los datos de clientes, servicios y reservas, además de los registros de funcionamiento del sistema.

¿Con qué se desarrolló?
Lenguaje de programación: Python.
Programación orientada a objetos (POO).
Almacenamiento de información mediante archivos JSON.
Manejo de excepciones y registros del sistema.

¿Cómo ejecutar el programa?
Descargar o clonar el repositorio.
Abrir la carpeta del proyecto en Visual Studio Code.
Ejecutar el archivo main.py.
Utilizar las opciones que aparecen en el menú principal.
