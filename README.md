SOFTWARE FJ

Sistema de gestión de servicios
Software FJ es un sistema desarrollado en Python para gestionar clientes, servicios y reservas. Su funcionamiento se realiza mediante un menú de opciones desde la terminal.

Funcionalidades

Registro de clientes.
Registro de servicios.
Creación de reservas.
Consulta de clientes registrados.
Consulta de servicios disponibles.
Consulta de reservas realizadas.
Almacenamiento permanente de información.
Manejo de excepciones y validación de datos.
Registro de eventos del sistema.

Tecnologías utilizadas

Python.
Programación orientada a objetos (POO).

Archivos JSON para almacenamiento de datos.
Ejecución del programa
Abrir la carpeta del proyecto en Visual Studio Code.
Abrir la terminal.
Ejecutar el siguiente comando:python main.py
